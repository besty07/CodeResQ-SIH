# 🚌 Real-Time Public Transport Tracking System  
### Smart India Hackathon 2025 | Team CodeResQ  
*Problem Statement ID: 25013 – Transportation & Logistics*

---

## 📌 Overview

This project is a **real-time public transport tracking web application** designed to improve bus accessibility in **small cities**.  
It enables commuters to track live bus locations on an interactive map while allowing drivers to share GPS coordinates directly from their devices.

The solution focuses on **simplicity, low bandwidth usage, and feasibility**, making it suitable for regions with limited infrastructure.

---

## 🎯 Problem Statement

In many small cities, passengers often do not know when the next bus will arrive, leading to long waiting times, overcrowding, and reduced trust in public transport systems.

---

## 💡 Solution

A GPS-based bus tracking system where:
- Drivers share live location using their phone’s GPS
- Users can view real-time bus positions on a map
- The system works even when dedicated GPS hardware is unavailable

---

## ✨ Key Feature

Real-time bus location tracking with live map visualization and separate driver/user portals optimized for low-bandwidth environments.

---

## 🧠 Technical Implementation

Developed a Node.js–based client–server system enabling real-time bus tracking using browser Geolocation API, REST APIs, and Leaflet.js with OpenStreetMap.

---

## 🧰 Tech Stack

| Layer | Technologies |
|-----|-------------|
| Frontend | HTML, Tailwind CSS, JavaScript |
| Backend | Node.js, Express.js |
| Maps | Leaflet.js, OpenStreetMap |
| APIs | REST |
| Location | Browser Geolocation API |

---


## ⚙️ How It Works

1. Driver starts location sharing using browser GPS  
2. Location data is sent to the backend server  
3. Server stores and updates live coordinates  
4. Users fetch and view bus location on an interactive map  
5. Location updates refresh automatically at fixed intervals  

---

## 🌍 Impact

Improves reliability and trust in public transport by providing transparent, real-time bus location updates for commuters in small cities.
